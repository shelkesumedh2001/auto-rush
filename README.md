# Auto Rush - 3D Endless Runner Racing Game 🏎️

A modern 3D endless runner racing game built with Three.js featuring stunning graphics, engaging gameplay, and comprehensive monetization features.

![Auto Rush](https://img.shields.io/badge/Game-3D%20Racing-blue) ![Platform](https://img.shields.io/badge/Platform-Web%20%26%20Mobile-green) ![Status](https://img.shields.io/badge/Status-Production%20Ready-success)

## 🎮 Game Features

### Core Gameplay
- **Full 3D Graphics**: Built with Three.js for immersive 3D experience
- **Endless Runner**: Infinite procedurally generated road with increasing difficulty
- **Lane-Based Movement**: Three lanes with smooth transitions
- **Jump Mechanic**: Avoid obstacles by jumping over them
- **Dynamic Speed**: Speed increases as you progress
- **Lives System**: Three lives with collision detection
- **Score Tracking**: Real-time score based on distance traveled

### Visual Features
- **3D Car Models**: Detailed player car with animated wheels
- **Dynamic Lighting**: Ambient, directional, and neon point lights
- **Particle Effects**: Glowing coins and power-ups
- **Fog Effects**: Atmospheric depth perception
- **Smooth Animations**: 60 FPS gameplay
- **Responsive Design**: Adapts to any screen size

### Power-Ups System
- **🛡️ Shield**: Protects from one collision
- **⚡ Speed Boost**: 2x speed for 10 seconds
- **🧲 Magnet**: Automatically collects nearby coins
- **✖️2 Double Coins**: 2x coin collection for 15 seconds

### Obstacles & Collectibles
- **Various Obstacles**: Boxes, cones, and barriers
- **Gold Coins**: Collectible currency
- **Random Power-Ups**: Spawn randomly during gameplay
- **Increasing Difficulty**: More obstacles as speed increases

## 🚀 Getting Started

### Quick Start
1. Clone the repository
```bash
git clone https://github.com/yourusername/auto-rush.git
cd auto-rush
```

2. Install dependencies (optional - for development server)
```bash
npm install
```

3. Run the game
```bash
npm start
```
Or simply open `index.html` in a modern web browser.

The game is ready for deployment to:
